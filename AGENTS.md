# Project entry point

Read `../WORKSPACE.md`, then `docs/resume.md`. Keep the handoff current so development can resume after context or usage limits. It overrides the earlier brainstorm in `../prompts/maze-shooter.md`. Record newly requested unfinished work in `tasks/` and remove finished trackers after their results are saved.

Install development tools with `npm ci` in this repository. Format changed Markdown files with `npm run format -- <files>` and verify them with `npm run format:check -- <files>`. These commands preserve embedded code examples. Use this repository's pinned formatter; do not borrow tools from another game's `node_modules`.
