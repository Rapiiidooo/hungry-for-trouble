## Code and operation

`sim.js`, `boss-attacks.js`, `machines.js`, `levels.js`, `floorplans.js` and `floor-shapes.js` own solo rules and layouts. `locked-wing.js` generates the five key layouts; `locks.js` owns deterministic pickups/opening and matching symbols. `lock-effects.js` reuses verified freezers for doors and draws original key sprites, with `locked-wing.css` for the ring/discovery. `main.js` owns assembly/input/UI. `view-rig.js`, `presentation-fx.js`, `campaign-fx.js`, `combat-fx.js`, `escape-scene.js`, `story.js` and `upgrade-art.js` implement presentation. `presentation.css` is the shared responsive layer; `mobile.css` owns the compact phone composition and `touch-aim.js` filters visible targets for bounded aiming assistance before input quantization; `credits.js` and `credits.css` own the staff roll. `arcade.js` owns unlocks and board helpers; `visibleFloorCount()` reveals 10, 20 or 25 floors. `campaign.js` validates full-run replays under `campaign-2`, yielding every 600 ticks so rooms keep advancing. `CAMPAIGN_BOARD` keeps the existing `campaign-1:all` storage key so old verified scores remain visible. Daily rules and its board version are unchanged. The twelve selected recipe asset modules and loader remain unchanged.

`multiplayer-sim.js` owns room rules; `room-client.js` handles polling/reconnect. `server/rooms.mjs` validates membership and advances matches at 60 Hz. Clients send five packed controls, never trusted position, health or score. Prediction is visual only. `scripts/serve.mjs` serves the APIs before static files.

Use Node 24 with `npm run dev`, no install or runtime API key. Development tools are independent: `npm ci` installs the pinned formatter and `npm run format -- <changed files>` formats Markdown without rewriting embedded examples. The abandoned game's dependency directory was removed at the owner's request; never use another game's formatter. Ignored `data/leaderboard.json` persists scores; rooms are memory-only. Hosting uses one Node process and a persistent leaderboard disk. `HOST`, `PORT` and `LEADERBOARD_FILE` are configurable. Static hosting supports solo only. Set `TRUSTED_PROXY_IPS` to exact proxy addresses and overwrite `X-Real-IP` at that proxy. Untrusted forwarding headers are ignored. `/healthz` exposes no host metadata. Server restart expires rooms/attempts and keeps scores; campaign saves renew their attempt through verified replay.
